# 🤖 Telegram-боти на Python — портфоліо

Розробляю Telegram-ботів для бізнесу під ключ: від ідеї й логіки до деплою на VPS.
У цьому репозиторії — три робочі демо-проєкти, які покривають найпоширеніші задачі:
продажі, онлайн-запис і AI-консультування. Кожен можна запустити за 5 хвилин і адаптувати під вашу нішу.

| Проєкт | Що вміє | Для кого |
|---|---|---|
| [🛍 **shop-bot**](shop-bot) | Каталог з фото, пошук, кошик, оформлення з фото чека, адмінка: товари, категорії, замовлення, статистика, розсилка | Магазини, кав'ярні, handmade, дропшипінг |
| [📅 **booking-bot**](booking-bot) | Запис на послуги: майстер → календар → вільний слот, нагадування, скасування, адмінка з графіками майстрів | Барбершопи, салони краси, клініки, автосервіси |
| [🤖 **ai-bot**](ai-bot) | AI-консультант на Claude API за базою знань компанії + збір заявок із контекстом розмови | Сервісні компанії, онлайн-школи, нерухомість |

## 🧰 Стек
**Python 3.12** · **aiogram 3** (FSM, роутери, middleware, CallbackData) · **SQLAlchemy 2.0 async** ·
SQLite / **PostgreSQL** · **APScheduler** · **Anthropic Claude API** · **Docker / docker-compose** · pydantic-settings

## ✅ Що є в кожному проєкті
- Чиста архітектура: `handlers / keyboards / db (models + repo) / services` — легко підтримувати й розширювати
- **Адмін-панель прямо в Telegram** — власнику не потрібен окремий сайт
- FSM-діалоги з валідацією, `/cancel` з будь-якого кроку, обробка «старих» кнопок і тексту замість кнопки
- Глобальний обробник помилок і логування
- Конфігурація через `.env`, демо-дані «з коробки», `Dockerfile` + `docker-compose.yml` для VPS
- Детальний README з інструкцією запуску
