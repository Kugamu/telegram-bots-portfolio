# 🤖 AI Consultant Bot — AI-консультант + збір заявок на Claude API

Telegram-бот, який **24/7 відповідає клієнтам на запитання за базою знань компанії** і
перетворює розмову на заявку для менеджера. Працює на Claude (Anthropic) — відповідає живою
мовою, пам'ятає контекст діалогу і не вигадує того, чого немає у вашому FAQ.

Демо налаштоване для компанії з ремонту квартир, але база знань — звичайний текстовий файл:
замініть його, і бот стане консультантом стоматології, автосалону, онлайн-школи чи інтернет-магазину.

> **Стек:** Python 3.12 · aiogram 3 · Anthropic Claude API · SQLAlchemy 2 (async) · SQLite / PostgreSQL · Docker

## ✨ Можливості

### Для клієнта
- 💬 Відповіді **природною мовою** на будь-які запитання про ціни, терміни, умови, гарантію
- 🧠 **Пам'ять діалогу** — можна уточнювати («а для двокімнатної?»)
- 🎯 Бот сам розпізнає готовність до покупки й пропонує кнопку **«📝 Залишити заявку»**
- 📝 Заявка за 3 кроки: ім'я → телефон (кнопкою) → опис задачі
- ⚡ Кнопки швидких запитань, «🔄 Новий діалог»

### Для власника (`/admin`)
- 🔥 **Миттєве сповіщення** про заявку разом з **останніми повідомленнями діалогу** — менеджер одразу бачить, що цікавить клієнта
- 📋 Заявки зі статусами (нова / в роботі / закрита)
- 📊 Статистика: користувачі, кількість запитань, заявки, **конверсія в заявку**, витрата токенів
- 🔄 **Оновлення бази знань без перезапуску** — відредагували `knowledge/faq.md`, натиснули кнопку

### Якість і контроль витрат
- Відповіді **лише з бази знань** — системні правила забороняють вигадувати ціни й умови
- **Prompt caching** системного промпту з базою знань — дешевші та швидші запити
- **Ліміт запитів** на користувача за годину — захист від зловживань і несподіваних рахунків
- Обмеження довжини історії та відповіді, налаштовувана «глибина міркувань» (`CLAUDE_EFFORT`)
- **Server-side fallback**: якщо основна модель відхилить запит, Anthropic автоматично повторить його на резервній
- Дружнє повідомлення + пропозиція заявки, якщо API тимчасово недоступний — клієнт не губиться
- Облік токенів кожної відповіді в БД, FSM з обробкою «тексту замість кнопки», логування

## 🚀 Запуск

1. Створіть бота в @BotFather і отримайте токен.
2. Отримайте ключ Claude API на [console.anthropic.com](https://console.anthropic.com) (API Keys).
3. Запустіть:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # Windows: copy .env.example .env
# впишіть BOT_TOKEN, ADMIN_IDS, ANTHROPIC_API_KEY
python -m bot
```

### Docker (VPS)
```bash
cp .env.example .env
docker compose up -d --build
```

Без `ANTHROPIC_API_KEY` бот теж запуститься: замість AI-відповіді запропонує залишити заявку.

### Налаштування `.env`
| Змінна | Опис | За замовчуванням |
|---|---|---|
| `ANTHROPIC_API_KEY` | ключ Claude API | — |
| `CLAUDE_MODEL` | модель | `claude-sonnet-5-5` |
| `CLAUDE_EFFORT` | `low` / `medium` / `high` | `low` |
| `KNOWLEDGE_FILE` | файл бази знань | `knowledge/faq.md` |
| `HISTORY_LIMIT` | скільки повідомлень пам'ятати | `12` |
| `RATE_LIMIT_PER_HOUR` | ліміт запитань на користувача | `30` |
