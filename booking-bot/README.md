# 📅 Booking Bot — онлайн-запис у барбершоп / салон краси

Telegram-бот, який замінює адміністратора на рецепції: клієнт сам обирає послугу, майстра,
дату й вільний час, а бот нагадує про візит і не дає записатися двом людям на один слот.
Власник керує послугами, майстрами та їхнім графіком прямо в Telegram.

Підходить для барбершопів, салонів краси, манікюру, масажу, стоматологій, автосервісів,
репетиторів — будь-якого бізнесу «запис на час».

> **Стек:** Python 3.12 · aiogram 3 · SQLAlchemy 2 (async) · APScheduler · SQLite / PostgreSQL · Docker

## ✨ Можливості

### Для клієнта
- 💈 Вибір **послуги** (з тривалістю й ціною) → **майстра**, який її виконує
- 📆 **Inline-календар**: активні лише дні, де справді є вільні місця; гортання місяців
- 🕐 **Вільні слоти** з урахуванням графіка майстра, тривалості послуги та вже зайнятих записів
- 📱 Контакти один раз — бот запам'ятовує ім'я і телефон для наступних записів
- ⏰ **Нагадування** за N годин до візиту з кнопками «👍 Буду» / «❌ Скасувати»
- 🗓 **Мої записи**: перегляд і скасування (з правилом «не пізніше ніж за N годин»)

### Для власника (`/admin`)
- 📋 **Записи** на сьогодні / завтра / 7 днів — компактний розклад + картка кожного запису
- ❌ Скасування адміністратором з **автоматичним повідомленням клієнту**, позначка «виконано»
- 💈 **Послуги**: додавання, зміна назви/ціни/тривалості, приховування, безпечне видалення
- 👤 **Майстри**: профіль, призначення послуг у 1 клік, **робочий графік по днях тижня**
- 🔔 Миттєві сповіщення адміну про нові записи та скасування
- 📊 **Статистика** за місяць: візити, скасування, виручка, завантаження майстрів, популярні послуги
- 📣 **Розсилка** акцій усім клієнтам (текст/фото/відео) з попереднім переглядом

### Надійність
- **Захист від подвійного бронювання**: слот перевіряється при виборі та ще раз при підтвердженні
- Нагадування через періодичну перевірку БД — **не губляться після перезапуску** бота
- Минулі записи автоматично закриваються як виконані (для коректної статистики)
- Ціна фіксується в момент запису — зміна прайсу не впливає на історію
- Навігація зберігається в callback_data — кнопки «Назад» працюють навіть після рестарту
- Коректні часові пояси (`TIMEZONE`), FSM з обробкою тексту замість кнопок, `/cancel` будь-де, логування

## 🏗 Архітектура

```
bot/
├── __main__.py           # запуск: Dispatcher + APScheduler
├── config.py             # налаштування з .env
├── states.py             # FSM-стани
├── db/
│   ├── models.py         # User, Service, Master, WorkingHours, Booking
│   ├── repo.py           # запити до БД
│   └── seed.py           # демо: 5 послуг, 3 майстри з графіками
├── services/
│   ├── slots.py          # розрахунок вільних слотів і доступних днів
│   ├── reminders.py      # нагадування + автозакриття записів
│   └── notify.py
├── handlers/
│   ├── start.py          # меню, прайс, контакти
│   ├── booking.py        # сценарій запису
│   ├── my.py             # мої записи, скасування
│   ├── fallback.py       # застарілі кнопки, помилки
│   └── admin/            # записи, послуги, майстри, графік, статистика, розсилка
├── keyboards/            # клавіатури, inline-календар, CallbackData
└── utils/
```

## 🚀 Запуск

### Локально
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # Windows: copy .env.example .env
# впишіть BOT_TOKEN та ADMIN_IDS
python -m bot
```

### Docker (VPS)
```bash
cp .env.example .env
docker compose up -d --build
docker compose logs -f
```

### Основні налаштування `.env`
| Змінна | Опис | За замовчуванням |
|---|---|---|
| `BOT_TOKEN` | токен від @BotFather | — |
| `ADMIN_IDS` | ID адмінів через кому | — |
| `TIMEZONE` | часовий пояс салону | `Europe/Kyiv` |
| `SLOT_STEP_MIN` | крок сітки слотів, хв | `30` |
| `BOOKING_DAYS_AHEAD` | горизонт запису, днів | `30` |
| `REMIND_HOURS` | нагадування за N годин | `2` |
| `CANCEL_MIN_HOURS` | скасування не пізніше ніж за N годин | `2` |
