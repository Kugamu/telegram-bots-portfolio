# 🛍 Shop Bot — Telegram-магазин з адмін-панеллю

Повноцінний інтернет-магазин усередині Telegram: каталог з фото, пошук, кошик, оформлення
замовлення з підтвердженням оплати та **адмін-панель прямо в боті** — без окремого сайту й CRM.
Демо налаштоване як магазин кави, але структура підходить для будь-якої ніші: одяг, косметика,
електроніка, квіти, handmade.

> **Стек:** Python 3.12 · aiogram 3 · SQLAlchemy 2 (async) · SQLite / PostgreSQL · Docker

## ✨ Можливості

### Для покупця
- 🗂 **Каталог** з категоріями, пагінацією та фото товарів
- 🔎 **Пошук** за назвою та описом (коректно працює з кирилицею)
- 🛒 **Кошик**: додати, ➖/➕ кількість, видалити позицію, очистити; контроль залишків на складі
- 📝 **Оформлення замовлення** покроково: ім'я → телефон (кнопкою «Надіслати номер» або вручну, з валідацією) → адреса НП → спосіб оплати
- 💳 **Оплата на карту з фото квитанції** або накладений платіж
- 📦 **Мої замовлення** зі статусами + автоматичні сповіщення, коли статус змінюється

### Для власника (`/admin`)
- 📦 **Товари**: додавання (покроковий майстер), редагування будь-якого поля, фото, залишки, приховування з каталогу, видалення
- 🗂 **Категорії**: створення, перейменування, безпечне видалення
- 🧾 **Замовлення**: фільтр за статусами, картка замовлення з контактами клієнта, перегляд чека, зміна статусу в 1 клік
- 🔔 **Миттєве сповіщення** адміну про нове замовлення (разом із фото чека та кнопками статусів)
- 📊 **Статистика**: користувачі, замовлення за добу, виручка, топ-5 товарів, товари, що закінчились
- 📣 **Розсилка** будь-якого контенту (текст/фото/відео) всім користувачам з попереднім переглядом, захистом від flood-лімітів і звітом про доставку

### Надійність
- FSM-діалоги: кнопки головного меню коректно перериваються з будь-якого кроку, `/cancel` скасовує будь-яку дію
- Обробка «старих» кнопок і тексту замість кнопки — бот підказує, а не падає
- При скасуванні замовлення товар автоматично повертається на склад
- Назви й ціни в замовленні фіксуються — редагування товару не змінює історію
- Глобальний обробник помилок + логування
- Розсилка відмічає користувачів, що заблокували бота

## 🏗 Архітектура

```
bot/
├── __main__.py        # точка входу, збірка Dispatcher, підключення роутерів
├── config.py          # налаштування з .env (pydantic-settings)
├── states.py          # FSM-стани
├── filters.py         # IsAdmin
├── middlewares.py     # сесія БД на кожен апдейт
├── db/
│   ├── models.py      # ORM-моделі SQLAlchemy 2.0
│   ├── repo.py        # усі запити до БД (repository-шар)
│   ├── engine.py
│   └── seed.py        # демо-дані
├── handlers/
│   ├── start.py       # /start, меню, мої замовлення
│   ├── catalog.py     # каталог і пошук
│   ├── cart.py
│   ├── checkout.py    # оформлення замовлення
│   ├── fallback.py    # застарілі кнопки, невідомі повідомлення, помилки
│   └── admin/         # адмін-панель (товари, категорії, замовлення, розсилка, статистика)
├── keyboards/         # inline/reply-клавіатури + типізовані CallbackData
├── services/notify.py # сповіщення
└── utils/             # форматування, універсальний render екранів
```

Хендлери не містять SQL — уся робота з БД у `db/repo.py`, тому перейти з SQLite на PostgreSQL
можна зміною одного рядка в `.env`.

## 🚀 Запуск

### Локально
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # Windows: copy .env.example .env
# впишіть BOT_TOKEN та свій ADMIN_IDS у .env
python -m bot
```

### Docker (VPS)
```bash
cp .env.example .env   # заповніть
docker compose up -d --build
docker compose logs -f
```

При першому запуску база наповнюється демо-товарами (`SEED_DEMO_DATA=true`).

### Налаштування `.env`
| Змінна | Опис |
|---|---|
| `BOT_TOKEN` | токен від @BotFather |
| `ADMIN_IDS` | Telegram ID адмінів через кому (дізнатися: @userinfobot) |
| `DATABASE_URL` | `sqlite+aiosqlite:///data/shop.db` або `postgresql+asyncpg://…` |
| `SHOP_NAME` | назва магазину в привітанні |
| `PAYMENT_DETAILS` | реквізити для оплати на карту |
| `SEED_DEMO_DATA` | наповнити БД демо-даними |
